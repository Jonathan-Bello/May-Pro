# May Pro

## Link del proyecto publicado

https://maypro.mx/

## Descripcion

Sitio web para May Pro. Presenta informacion comercial de la marca, servicios o productos, secciones de contacto y una experiencia visual orientada a conversion.

## Tecnologias usadas

- Astro
- Tailwind CSS
- TypeScript
- Swiper
- Remix Icon

## Requisitos

- Node.js 18+
- npm

## Retos tecnicos

- Construir una landing comercial clara y responsive.
- Organizar la informacion de la marca en secciones reutilizables.
- Optimizar contenido visual para carga rapida.
- Preparar el proyecto para publicacion en dominio personalizado.
